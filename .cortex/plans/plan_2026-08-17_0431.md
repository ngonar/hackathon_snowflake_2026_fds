## Context

The existing Ngonaroid FDS (Fraud Detection System) is a remittance fraud analysis engine with:
- **ApiServer**: FastAPI app that publishes transactions to Snowflake `REMITTANCE_TRX` table
- **FdsAgent**: LangChain-based agent that polls Snowflake `PENDING_TRANSACTIONS`, enriches from local SQLite, calls Cortex Complete for fraud analysis, and updates status via MCP
- **McpServer**: FastMCP server wrapping the remittance API for tool-based access

The current architecture has limitations:
1. Enrichment data (users, recipients, transaction history) lives in local SQLite, not Snowflake
2. The fraud analysis logic is monolithic in `agent.py`
3. No modular CoCo CLI skills exist for interactive fraud reasoning

## Implementation Steps

### 1. Create Snowflake schema and tables for transaction history

Create `NGONAROID_FDS.FDS` schema with tables: `USERS`, `RECIPIENTS`, `TRANSACTIONS`, `FRAUD_ANALYSIS_LOG` — mirroring the SQLite models but in Snowflake AI Data Cloud.

### 2. Create modular CoCo CLI skill: `fds-transaction-profiling`

**File**: `.cortex/skills/fds-transaction-profiling/SKILL.md`

This skill queries Snowflake transaction history tables to build sender/recipient behavioral profiles (average amounts, frequency, typical recipients, time-of-day patterns). Used as reasoning context before fraud determination.

### 3. Create modular CoCo CLI skill: `fds-anomaly-detection`

**File**: `.cortex/skills/fds-anomaly-detection/SKILL.md`

This skill runs anomaly scoring SQL against the transaction tables — detecting velocity spikes, amount deviations, unusual hours, new-recipient bursts. Returns structured anomaly indicators.

### 4. Create modular CoCo CLI skill: `fds-fraud-classification`

**File**: `.cortex/skills/fds-fraud-classification/SKILL.md`

This skill takes enriched transaction context + anomaly signals and invokes Cortex Complete (via `AI_COMPLETE`) to classify into one of the 7 fraud types. Produces the structured `FraudAnalysisResult` output.

### 5. Create modular CoCo CLI skill: `fds-investigation`

**File**: `.cortex/skills/fds-investigation/SKILL.md`

A meta-skill for ad-hoc fraud investigation — allows querying the `FRAUD_ANALYSIS_LOG`, drilling into specific flagged transactions, tracing circular transfers, and generating compliance reports.

### 6. Create the SQL scripts referenced by skills

**Files**: `.cortex/skills/*/scripts/*.sql`

Each skill references executable SQL scripts that perform the actual Snowflake queries (profiling, anomaly detection, historical lookups).

### 7. Create the Snowflake DDL setup script

**File**: `.cortex/skills/fds-setup/setup.sql`

DDL to create the `NGONAROID_FDS.FDS` schema, tables, streams, and tasks that the skills operate on.
