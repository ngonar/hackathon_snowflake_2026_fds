## Context

- The USERS table in `SNOWFLAKE_LEARNING_DB.FDS` has no `BASE_CURRENCY` column — source currency is hardcoded as `"USD"` in `transactions.py` (lines 37, 152).
- The ClientApp is a React/Vite SPA with inline-styled "glass card" components, using `lucide-react` icons.
- The API uses FastAPI with Snowflake connector, CRUD helpers, and Pydantic schemas.
- The app navigates via a `view` state (`landing | dashboard | admin`); we'll add `settings` as a new view.

## Implementation Steps

### 1. Database: Add BASE_CURRENCY column to USERS table
```sql
ALTER TABLE SNOWFLAKE_LEARNING_DB.FDS.USERS ADD COLUMN BASE_CURRENCY VARCHAR(10) DEFAULT 'USD';
```

### 2. Backend: Add API endpoint for updating base currency
- **`schemas.py`** — Add `BaseCurrencyUpdate` schema and include `base_currency` in `UserResponse`
- **`routers/users.py`** — Add `PUT /users/me/settings` endpoint to update base currency
- **`crud.py`** — Add `update_user_base_currency(conn, user_id, currency)` function

### 3. Backend: Use user's base currency in transactions
- **`routers/transactions.py`** — Replace hardcoded `"USD"` with `current_user.get("base_currency", "USD")` in both single and bulk transfer endpoints

### 4. Frontend: Add API method
- **`services/api.js`** — Add `updateBaseCurrency(currency)` method calling `PUT /api/users/me/settings`

### 5. Frontend: Create Settings/Configuration page
- **`src/components/SettingsPage.jsx`** — New component with a card to select base currency (dropdown of supported currencies: USD, EUR, GBP, KES, INR, PHP, MXN), with save button. Follows existing glass card + inline style pattern.

### 6. Frontend: Add navigation to Settings
- **`src/App.jsx`** — Add `'settings'` to view state, add a Settings nav button (gear icon) in the header, render `<SettingsPage>` when view is `'settings'`
