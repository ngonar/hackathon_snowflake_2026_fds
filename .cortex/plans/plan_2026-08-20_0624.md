## Context

The Send Money card in `UserDashboard.jsx` currently allows single transfers (select recipient, enter amount, submit). The backend `POST /transactions` endpoint creates one transaction at a time. The client uses a proxy (`/api` → backend) via `server.js`.

Key patterns:
- Backend: FastAPI with SQLAlchemy, Pydantic schemas, background tasks for queue publishing
- Frontend: React with inline state, `api.js` service layer using `fetch`
- The `api.js` `request()` function currently always sets `Content-Type: application/json` — needs a FormData path for file uploads

## Implementation Steps

### 1. Backend — New `POST /transactions/bulk` endpoint in `ApiServer/app/routers/transactions.py`

- Accept a CSV file via `UploadFile` (FastAPI)
- Parse CSV expecting columns: `recipient_id`, `source_amount`
- Validate each row (recipient exists and belongs to user, amount > 0)
- Create transactions in a loop (reusing existing `crud.create_transaction` logic)
- Publish each to the queue via background tasks
- Return a summary response: `{ total: N, successful: [...], failed: [{row, error}] }`

### 2. Backend — Add bulk transfer schema in `ApiServer/app/schemas.py`

- `BulkTransferResult` schema with `total`, `successful` (list of `TransactionResponse`), `failed` (list of row errors)

### 3. Frontend — Add `bulkTransfer` method in `ClientApp/src/services/api.js`

- New method that sends a `FormData` with the CSV file
- Update the `request()` function to skip setting `Content-Type: application/json` when body is `FormData`

### 4. Frontend — Add CSV upload UI to the Send Money card in `ClientApp/src/components/UserDashboard.jsx`

- Add a "Bulk Transfer" toggle/tab below the existing single transfer form
- File input accepting `.csv` files
- A "Download Template" link so users know the expected format
- Upload button that calls `api.bulkTransfer(file)`
- Display results summary (successes + errors) after upload
