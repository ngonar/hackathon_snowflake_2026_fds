## Context

The ClientApp is a React SPA (Vite + JSX, no TypeScript) with inline styles and lucide-react icons. The Admin Panel (`AdminPanel.jsx`) shows KYC management, exchange rates, and a transaction list with risk breakdown. The ApiServer is FastAPI with routers, and the `server.js` proxies `/api` to the backend. Snowflake already has `SNOWFLAKE_LEARNING_DB.FDS` with TRANSACTIONS, FRAUD_ANALYSIS_LOG, REMEDIATION_ACTIONS, WALLET_FREEZE_LOG, and KYC_REVERIFICATION_QUEUE tables.

The NL query feature needs:
1. A backend endpoint that accepts natural language, translates to SQL via Cortex AI_COMPLETE, executes it, and returns results
2. A frontend chat-style component in the Admin Panel
3. A CoCo CLI skill for the NL query reasoning

## Implementation Steps

### 1. Add NL Query API endpoint to ApiServer

**File**: `ApiServer/app/routers/admin.py`

Add `POST /admin/investigate` endpoint that:
- Accepts `{"query": "Show all transactions..."}` 
- Connects to Snowflake, calls `AI_COMPLETE` to translate NL → SQL (constrained to SELECT only on FDS tables)
- Executes the generated SQL
- Returns `{"sql": "...", "results": [...], "explanation": "..."}`

### 2. Add Snowflake NL-to-SQL helper module

**File**: `ApiServer/app/nl_query.py`

Contains:
- Schema context string (table definitions for the AI)
- `translate_and_execute(query: str)` function that:
  - Builds a prompt with table schemas + user question
  - Calls `SNOWFLAKE.CORTEX.AI_COMPLETE` to generate safe SELECT SQL
  - Validates it's a read-only query (no DML)
  - Executes and returns results + generated SQL

### 3. Add API client method

**File**: `ClientApp/src/services/api.js`

Add `investigateQuery: (query) => request(...)` to the api object.

### 4. Create FraudInvestigator component

**File**: `ClientApp/src/components/FraudInvestigator.jsx`

A chat-style AI assistant panel with:
- Text input for natural language queries
- Message history (user queries + AI responses)
- Results rendered as a table with highlighted risk indicators
- SQL preview toggle (show generated SQL)
- Pre-built suggestion chips ("High-risk txns last 24h", "Frozen wallets", etc.)

### 5. Integrate into AdminPanel

**File**: `ClientApp/src/components/AdminPanel.jsx`

Add a tab/section for "AI Investigator" that renders the `FraudInvestigator` component.

### 6. Create CoCo CLI skill: `fds-nl-query`

**File**: `.cortex/skills/fds-nl-query/SKILL.md`

Skill that defines the NL-to-SQL translation patterns, table schemas, and example queries for the CoCo agent to use when compliance officers ask questions.
