# ClientApp

Frontend client application for the Ngonaroid Remittance platform. Built with React 19 and Vite, it provides the user interface for managing remittance transactions, user accounts, and viewing fraud detection results.

## Prerequisites

- Node.js 18+
- npm

## Installation

```bash
cd ClientApp
npm install
```

## Run (Development)

```bash
npm run dev
```

## Run (Production Build)

```bash
npm run build
npm run preview
```

## Browser Access

- Development: http://localhost:5173/
- Preview (production build): http://localhost:4173/
