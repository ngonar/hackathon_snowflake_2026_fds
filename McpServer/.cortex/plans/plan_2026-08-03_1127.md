## Context

Your `server.py` is a FastMCP server that exposes RemitApp API operations as MCP tools. It connects to:
- An external API (`REMIT_API_URL`, defaults to `http://localhost:8000`)
- RabbitMQ (`localhost:5672`)

Snowflake supports deploying custom MCP servers on **Snowpark Container Services (SPCS)**. The server gets containerized, pushed to Snowflake's image registry, run as an SPCS service, and registered as a `CUSTOM MCP SERVER` object.

Key adaptations needed:
1. The server must use `streamable-http` transport (currently defaults to `stdio`)
2. A health check endpoint is needed for SPCS readiness probes
3. External Access Integrations are needed for the RemitApp API and RabbitMQ connections

## Implementation Steps

### 1. Modify `server.py` for SPCS compatibility
- Change `mcp.run()` to `mcp.run(transport="streamable-http")`
- Set host to `0.0.0.0` and port to `8080`
- Add a health check HTTP endpoint on port `8081`

### 2. Create `Dockerfile`
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8080 8081
CMD ["python", "server.py"]
```

### 3. Create SPCS spec file (`spec.yaml`)
Define the container, ports, readiness probe, and external access.

### 4. Run SQL to set up Snowflake infrastructure
- Create a database/schema (or use existing)
- Create an image repository
- Create a compute pool
- Create an External Access Integration for the RemitApp API and RabbitMQ hosts
- Create network rules for outbound access

### 5. Build and push the Docker image
```bash
docker build -t <repo_url>/remitapp-mcp:latest .
docker login <repo_url>
docker push <repo_url>/remitapp-mcp:latest
```

### 6. Create the SPCS service
```sql
CREATE SERVICE remitapp_mcp_service
  IN COMPUTE POOL my_compute_pool
  FROM SPECIFICATION ...
  EXTERNAL_ACCESS_INTEGRATIONS = (remitapp_eai);
```

### 7. Register as Custom MCP Server
```sql
CREATE CUSTOM MCP SERVER remitapp_mcp
  SERVICE = remitapp_mcp_service
  ENDPOINT = mcp_endpoint
  PATH = '/mcp';
```

## Verification
